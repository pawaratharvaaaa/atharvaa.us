music-model — Song Prediction & Identification Studio

An intelligent dual-engine ML system for music streaming apps.

role
Solo Engineer
duration
2026
team
Solo
stack
Python · FastAPI · ML · TF-IDF · Web Audio
repo↗ github.com/pawaratharvaaaa/music-model
“even if you spell it 'bheemian rapsody', it finds the song.”
note»phonetic Double Metaphone + n-gram TF-IDF«
note»acoustic vector modeling across BPM, Energy, Valence«
note»generates seamless 10-track sonic transitions«

The problem

You have a song stuck in your head but can't remember the exact spelling, or you want the next track to match your energy level seamlessly. Typical search engines fail at both.

Engine 1 — Song Identification

Identifies tracks from misspelled titles or partial lyric fragments. It dynamically blends fuzzy Levenshtein distance, phonetic Double Metaphone encodings, and character n-gram TF-IDF matrices.

Engine 2 — Next-Song Prediction

Predicts what track should play next based on multi-dimensional acoustic similarity: BPM, Energy, Danceability, Valence, Acousticness, and Genre vectors.

The stack

Python, FastAPI, Scikit-learn, TF-IDF, Web Audio API testing workbench.

What it does

Scans your local device storage, organizes music by metadata tags, and renders a clean Apple Music–inspired desktop player. Synchronized lyrics scroll smoothly alongside audio playback using sidecar .lrc files or cached offline LRCLIB responses.

The stack

TypeScript + Vite. Electron for native desktop packaging, with dual support for browser mode (npm run web) and native desktop mode (npm run dev).
